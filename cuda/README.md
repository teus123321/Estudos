# Estudos de CUDA C++

CUDA é uma plataforma de programação paralela da NVIDIA. Neste repositório, os exemplos usam **CUDA C++**, que permite executar partes do código em uma GPU NVIDIA.

## Exemplos

- [POO em CUDA — os quatro pilares](poo-4-pilares/README.md): encapsulamento, abstração, herança e polimorfismo com personagens de um jogo.

> Não confunda: **CUDA não é C puro**. O código `.cu` utiliza C++ e extensões próprias do CUDA, compiladas com `nvcc`.
